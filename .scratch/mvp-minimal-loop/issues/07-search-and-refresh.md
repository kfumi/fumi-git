# 07 — 搜索过滤 + 刷新与 .git 监听

**What to build:** 工具栏搜索框：按提交信息或作者做子串过滤（已加载数据范围内，前端 store 层实现，无索引），图谱列表实时收窄，清空即恢复。`.git` 目录文件监听（Rust 侧 notify）：检出、提交（外部终端发生）、分支变化等事件触发图谱/状态自动刷新；工具栏保留手动刷新按钮。外部修改（如在终端 commit）后图谱自动出现新提交。

监听需防抖（一次操作触发多次文件事件），且只在仓库打开时激活、切换仓库时换绑。
