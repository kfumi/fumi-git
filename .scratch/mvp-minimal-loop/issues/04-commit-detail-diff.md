# 04 — 提交详情与 diff 面板

**What to build:** 右侧常驻详情面板（396px，布局定稿见 docs/design/ui-spec.md）：选中提交后显示完整提交信息、作者、相对/绝对时间、短 hash、所属 ref、父提交；下方为变更文件列表（路径 + 增删行数统计，M/A/D 徽章）；点选文件或默认展开第一个文件，显示逐行 diff——行号、增删着色、hunk 头强调色、等宽字体、横向可滚动。合并提交显示父提交引用与说明（无直接 diff 的空态）。

Rust 侧新增 `get_commit_detail`：基于 git show 类命令解析出元信息 + 每文件统计 + 补丁文本，结构化返回。测试沿用封装层夹具矩阵，新增"新增/修改/删除/重命名/二进制文件"用例。

**Blocked by:** 02（提交数据流）。

**Status:** ready-for-agent

- [ ] 点选任意提交，详情面板元信息与图谱行一致（hash/作者/ref）
- [ ] 文件列表增删行数与真实仓库一致；重命名显示为 R 徽章
- [ ] diff 逐行着色正确：新增绿/删除红/上下文灰、hunk 头强调、行号列对齐
- [ ] 二进制文件显示占位说明而非乱码
- [ ] 合并提交显示父提交引用与无 diff 空态
- [ ] 封装层解析测试覆盖新增/修改/删除/重命名/二进制夹具
