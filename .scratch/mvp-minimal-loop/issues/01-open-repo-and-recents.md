# 01 — 打开仓库与最近列表

**What to build:** 用户首次启动看到引导页；通过系统目录选择器选择一个文件夹后，后端验证它是否为 git 仓库：是则打开并进入主界面空态，否则显示引导提示（该目录不是 git 仓库）。最近打开的仓库列表持久化到本地配置（JSON，应用配置目录），重启后仍在，可一键切换当前仓库。主题三态（深/浅/跟随系统）的选择也持久化并在启动时恢复。

本工单同时建立 git 命令封装层骨架（进程 spawn、输出捕获、错误类型）与 Rust 测试夹具构造器（临时目录建真实仓库），这是后续所有工单的承重基础设施。目录选择使用 Tauri 对话框插件。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 选择非 git 目录时，UI 显示引导提示而非报错或空白
- [ ] 打开有效仓库后，主界面显示该仓库名与当前分支
- [ ] 最近仓库列表跨重启保留，可切换、可从列表移除
- [ ] 主题选择跨重启保留；"跟随系统"模式响应系统外观实时变化
- [ ] 封装层对"非仓库目录"返回结构化错误，测试覆盖（真实夹具，不 mock git）
- [ ] Windows 路径全部经抽象处理，无硬编码分隔符
