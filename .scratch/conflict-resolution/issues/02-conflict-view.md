# 02 — 冲突解决视图：三方对比 + 文件级采用 + 标记已解决 + 继续合并

**What to build:** 改动 tab 的冲突文件组里点开一个文件，右栏展示该冲突的三方信息（我方 `:2:`、对方 `:3:`、工作区当前结果，共同祖先 `:1:` 可参考）；文件级一键「整个文件采用我方 / 对方版本」（选边即 `checkout --ours/--theirs` 并标记已解决）；用户也可在外部编辑器手动改完（提供「在编辑器打开」入口），无冲突标记后点「标记已解决」执行 `git add`；全部冲突解决后「继续合并」完成合并提交（沿用 MERGE_MSG，不弹编辑器）。

**Blocked by:** 01（operation 契约与 stages 读取）

**Status:** ready-for-agent

- [ ] 冲突文件行点击 → 右栏展示三方对比（ours/theirs 与工作区结果），可辨识各自来源
- [ ] 「采用我方 / 采用对方」整文件选边后该文件立即从冲突组消失（进入已暂存）
- [ ] 「在编辑器打开」用系统默认应用打开该文件
- [ ] 「标记已解决」在文件仍有冲突标记时给出警示，确认后才 add
- [ ] 全部冲突解决后「继续合并」可用并完成合并提交；非合并状态下不渲染这些动作
- [ ] Rust 夹具测试覆盖 stages 读取、选边+add、merge --continue 的提交拓扑；store 测试覆盖弹窗与状态流转
