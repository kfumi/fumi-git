# 03 — 冲突块逐块取舍

**What to build:** 冲突解决视图把工作区结果中的 `<<<<<<< / ======= / >>>>>>>` 标记解析为高亮块序列，每块提供「采用我方 / 采用对方」两个动作；选择后由纯函数把剩余块与无冲突内容拼装成新文件内容写回工作区（不自动 add），用户可继续处理其余块或到外部编辑器微调，最后「标记已解决」。解析与拼装为纯函数，vitest 直测。

**Blocked by:** 02（冲突视图挂载点）

**Status:** ready-for-agent

- [ ] 工作区结果中的冲突块被解析并高亮分块，块数正确（含连续多块、嵌套转义等边界由测试覆盖）
- [ ] 每块「采用我方 / 采用对方」后文件内容正确拼装写回，其余块保留
- [ ] 全部块处理完后文件无冲突标记，可「标记已解决」
- [ ] 解析/拼装为纯函数并有 vitest 单元测试（空块、缺标记、CRLF 等边界）
- [ ] 写回后不自动 add；「标记已解决」才执行 git add
