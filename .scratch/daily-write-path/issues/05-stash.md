# 05 — stash 全套:入列 / 列表 / 只读 diff / 恢复 / 删除

**What to build:** 开发者把中断的半成品一键存入 stash(可附可选描述),在侧栏新增的 stash 区看到条目列表(描述与时间),展开任意条目只读查看其 diff,再决定「恢复(保留副本)/ 恢复(弹出)/ 删除」。恢复弹出遇到冲突时报错且条目必须保留,存档不会在失败中丢失;冲突文件清单的展示若分叉拉取票已落地则复用其 UI。

**Blocked by:** 01(对话框基元用于描述输入;diff 渲染复用现有组件)

**Status:** ready-for-agent

- [ ] 一键 stash:脏改动全部入列,工作区变干净;附描述时条目展示描述,否则展示默认信息
- [ ] stash 列表位于侧栏新 section,含描述(或首行信息)与时间
- [ ] 展开条目可只读查看该 stash 的 diff,复用现有 diff 渲染
- [ ] 「恢复(保留副本)」后改动回到工作区且条目仍在;「恢复(弹出)」成功后条目移除
- [ ] 恢复弹出遇冲突:给出可读报错且条目保留,仓库处于冲突态(处理出口见分叉拉取票)
- [ ] 删除条目需确认,删除后条目消失
- [ ] 仅支持全量 stash,部分暂存不在范围
