# 02 — 分支生命周期:新建 / 删除 / 改名

**What to build:** 开发者在侧栏即可完成分支全生命周期的日常管理:顶部入口或右键新建分支(默认创建并迁出,可勾选「仅创建」;重名、非法名称在表单即时校验反馈);右键删除分支(已合入一次确认即删;未合入先展示未合入提交数,二次明确标注「强制删除」的确认后才删;当前分支删除项禁用并说明原因);右键改名并在侧栏、图谱 ref 徽章、当前分支标识处同步更新。

**Blocked by:** 01(右键菜单/对话框基元、迁出能力)

**Status:** ready-for-agent

- [ ] 新建分支默认「创建并迁出」,勾选「仅创建」则停留在原分支
- [ ] 重名、非法字符等名称问题在表单提交前即时反馈,不等待 git 报错
- [ ] 删除已合入分支:一次确认即删,分支从侧栏与图谱徽章消失
- [ ] 删除未合入分支:先展示未合入提交数,二次确认(明确标注强制删除)后才执行
- [ ] 当前分支的「删除」菜单项禁用并说明原因
- [ ] 改名后侧栏、图谱 ref 徽章、当前分支标识同步更新
- [ ] Rust 夹具测试覆盖建/删(已合入与未合入)/改名与已合入检测;store 测试覆盖各操作后刷新
