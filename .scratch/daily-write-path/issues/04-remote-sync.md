# 04 — 远程同步补全:push -u + 分叉拉取最小 merge

**What to build:** 开发者推送没有上游的分支时,弹出远程选择框(远程列表读自 git remote,默认 origin,仅一个远程时锁定),确认后建立关联并推送,不再被要求去终端。拉取遇到本地与远程分叉时,弹出「合并 origin/<分支> 到当前分支」的确认框,确认后应用内完成 merge;真产生冲突时展示冲突(未合入)文件清单,并提供「中止合并」把仓库完整恢复到合并前;冲突的解决动作本批留给终端。

**Blocked by:** 01(确认/选择对话框基元)

**Status:** ready-for-agent

- [ ] 无上游分支推送:弹框列出远程,单远程时锁定默认项;确认后推送成功、上游关联建立、ahead 徽章归零
- [x] 多远程仓库可选择目标远程,选择被正确传递（工具栏推送分裂按钮：主体推上游，caret 菜单逐远程 + 「推到全部远程」；`push_to`/`push_all_remotes` 不改上游关联）
- [ ] pull 分叉:弹确认框并显示合并目标;确认后 merge 完成,图谱出现合并提交
- [ ] merge 冲突:展示冲突文件清单(带冲突状态标识);「中止合并」仅在合并进行中可用,执行后仓库恢复到合并前状态
- [ ] 合并进行中的状态在 UI 可辨识
- [ ] Rust 夹具测试覆盖带 -u 的推送、远程列表、merge、冲突清单解析、中止合并;store 测试覆盖确认弹窗触发条件与冲突态展示
- [ ] 本批最大的一张票:若在单个上下文窗口内吃紧,可先交付 push -u 半场再续 merge 半场,但两半各自保持可演示
