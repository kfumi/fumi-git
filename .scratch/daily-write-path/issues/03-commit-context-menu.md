# 03 — 图谱提交右键:迁出到 `<分支>` / 在此新建分支 / reset 三选

**What to build:** 开发者在提交图谱上右键任意提交即可按位置操作:提交挂着本地分支时菜单动态显示「迁出到 <分支名>」(等同侧栏迁出,含安全拦截);任意提交可「在此新建分支」(复用新建分支表单,默认建完即迁出);任意提交可「将当前分支重置到此」,可选软/混合/硬三种模式,硬重置必过脏树安全拦截。不提供对任意提交的直接迁出(detached HEAD)入口。

**Blocked by:** 01(UI 基元、迁出、安全模型), 02(新建分支表单复用)

**Status:** ready-for-agent

- [ ] 挂本地分支的提交右键可见「迁出到 <分支名>」,行为与侧栏迁出一致(含脏树拦截)
- [ ] 无本地分支的提交不出现迁出项(不做 detached HEAD)
- [ ] 「在此新建分支」复用 02 的表单与校验,默认创建并迁出
- [ ] reset 三种模式各自生效:分支指向目标提交,工作区/暂存区状态符合软/混合/硬语义
- [ ] reset --hard 且工作区脏时被安全模型拦截确认,确认文案与实际行为一致
- [ ] reset 后图谱、状态面板、ahead/behind 全部刷新
- [ ] Rust 夹具测试覆盖三种 reset 模式的外部行为;store 测试覆盖拦截触发与刷新联动
