# 01 — 基础切片:UI 基元(右键菜单 + 确认/选择对话框)+ 分支迁出 + 脏树拦截安全模型

**What to build:** 开发者右键侧栏任意本地分支选择「迁出」即切换过去,图谱高亮、状态面板与 ahead/behind 随动刷新;工作区有未提交改动时操作被拦截,弹出列出受影响文件的选择框,由用户在「带着改动迁出 / stash 后迁出 / 取消」中知情选择。本票同时交付两个基础 UI 组件——右键菜单与确认/选择对话框(实现前先在 ui-spec 增补条目,遵循规则先行),以及「操作前检查脏工作树 → 拦截 → 弹选择」的安全模型,供后续 reset/丢弃等销毁类操作复用。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 干净工作树:右键本地分支迁出成功;当前分支标识、图谱 ref、状态面板、ahead/behind 徽章全部刷新
- [ ] 脏工作树迁出被拦截:选择框列出脏文件;「带着改动迁出」成功且改动保留;「stash 后迁出」将改动安全存入 stash 后切换、不自动恢复(以仓库实际 stash 状态验证);「取消」不产生任何变化
- [ ] git 自身拦截迁出时(改动与目标分支冲突),错误被规整为可读中文提示而非裸报错
- [ ] 右键菜单与确认/选择对话框组件遵循既有设计令牌;ui-spec 已增补两个基元的条目
- [ ] 单击分支保持现有「仅定位」行为不变
- [ ] Rust 侧真实 git 夹具测试覆盖迁出与脏树报错形态;store 测试(mock IPC)覆盖操作后刷新联动与拦截触发条件
- [ ] UI 组件不做单元测试(仓库约束),以可运行演示验收
