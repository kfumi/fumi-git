# FumiGit UI 设计规范 v1

> 2026-10-06 由 UI 原型对比确定。原型问题："FumiGit 主界面应该长什么样？哪种布局最'专业好看'？"
> 三个结构化变体（工作台三栏 / 沉浸图谱 / 仓库地图）经浏览器实际渲染对比后，**变体 A（工作台三栏）胜出**。
> 全量原型（含落选变体与切换器）归档于分支 `prototype/ui-variants`（`prototype/index.html`）。

## 1. 布局：三栏工作台

```
┌────────────────────────────────────────────────────────────┐
│ titlebar 34px  FumiGit — 仓库名                    ─ ▢ ✕  │
├────────────────────────────────────────────────────────────┤
│ toolbar 42px  仓库 · 分支▾ · 拉取/推送/抓取        搜索…  │
├──────────┬──────────────────────────────┬──────────────────┤
│ 侧栏     │ 提交图谱（Canvas）            │ 提交详情          │
│ 216px    │ 行高 52px，图宽 96px          │ （消息/元信息/    │
│ 仓库列表 │                               │  文件变更/diff）  │
│ 分支↑↓   ├──────────────────────────────┼──────────────────┤
│ 标签     │                               │ 工作区（暂存区）  │
│ 远程     │                               │ + 提交信息框      │
└──────────┴──────────────────────────────┴──────────────────┘
```

- 主操作面是**提交图谱列表**，右侧面板随选中行联动（详情 + diff + 工作区常驻）。
- 栏宽**可拖拽调整**（2026-10-06 增补）：左/中/右三栏分割线 + 右栏内详情/工作区分割线均可拖；react-resizable-panels（v3 PanelGroup）实现，百分比约束 侧栏 12–25% / 图谱 ≥30% / 右栏 20–44%，上下 详情 ≥16% / 工作区 ≥20%；默认比例 17:52:31（≈216/1fr/396 @1280）与 57:43（≈1.3:1），autoSaveId 持久化到 localStorage；分隔线 1px 视觉线 + 8px 命中区（`cursor-col/row-resize`），悬停命中区变 hover 色、细线变 accent，拖拽中保持高亮。
- 图谱列：SVG/Canvas 绘制，lane 步进 15px，节点 r=4（HEAD r=5.5，描边 2px 背景色）。
- 行内信息：提交信息 + ref 徽章（分支/远程/HEAD/标签）· 作者头像+名字 · 相对时间 · 短 hash。
- 从落选变体吸收：B 的"搜索框 Ctrl K 提示"样式进入工具栏；B 的底部状态栏**暂不引入**（A 的右下工作区已承担该职责，避免重复）。

### 字体

- UI：`"IBM Plex Sans", "PingFang SC", "Microsoft YaHei", sans-serif`
- 等宽（hash/diff）：`"IBM Plex Mono", "Cascadia Code", Consolas, monospace`
- 基准字号 13px，行内元信息 11.5–12px，diff 11.5px。

### diff 配色

- 新增行：底 `rgba(63,178,127,.12)`，字 `#7EDCB2`（浅色：底 `.14`，字 `#147A4C`）
- 删除行：底 `rgba(242,112,138,.10)`，字 `#F79CA9`（浅色：底 `.12`，字 `#B3384E`）
- hunk 头：底 `--accent-soft`，字 `--accent-ink`

## 3. 状态徽章

- 分支 ref：`--accent-soft` 底 + `--accent-ink` 字；远程 `origin/*`：描边幽灵款；HEAD：`--accent` 实底白字；标签 `⚑`：琥珀软底。
- 文件状态：M 琥珀 / A 绿 / D 玫红，14px 圆角小方块。
- 分支树计数：↑2 绿 / ↓1 琥珀。

## 4. 落选方案备忘

- **B 沉浸图谱**：全宽流 + 右滑抽屉。行两行式设计（第二行：作者·时间·文件数）值得未来在"详情模式"里参考。
- **C 仓库地图**：横向时间轴泳道。作为远期"图谱第二视图"保留想象，v1 不做。
