# FumiGit UI 设计规范 v1

> 2026-10-06 由 UI 原型对比确定。原型问题："FumiGit 主界面应该长什么样？哪种布局最'专业好看'？"
> 三个结构化变体（工作台三栏 / 沉浸图谱 / 仓库地图）经浏览器实际渲染对比后，**变体 A（工作台三栏）胜出**。
> 全量原型（含落选变体与切换器）归档于分支 `prototype/ui-variants`（`prototype/index.html`）。

## 1. 布局：三栏工作台

```
┌────────────────────────────────────────────────────────────┐
│ titlebar 34px  FumiGit — 仓库名                    ─ ▢ ✕  │
├────────────────────────────────────────────────────────────┤
│ toolbar 42px  仓库 · 分支▾ · 拉取/推送/抓取        搜索…  │
├──────────┬──────────────────────────────┬──────────────────┤
│ 侧栏     │ [改动] [历史] tab             │ 提交详情          │
│ 216px    │ 历史：提交图谱（默认，主角）   │ （消息/元信息/    │
│ 仓库列表 │      行高 52px，图宽 96px     │  文件列表）       │
│ 分支↑↓   │ 改动：暂存/未暂存 + 提交框     ├──────────────────┤
│ 标签     │                              │ 文件 diff（多tab）│
│ 远程     │                              │                  │
└──────────┴──────────────────────────────┴──────────────────┘
```

- 中栏**改动 / 历史 双 tab**（2026-10-06 增补，GitHub Desktop 式）：**默认选中「改动」**；历史 = 提交图谱列表（图谱是主角）；改动 = 工作区（已暂存/未暂存分组 + 提交信息框），自右下面板整体迁入。tab 选中态用 accent-soft 底 + accent 描边；两个 tab 保持挂载，来回切换不丢图谱滚动位置。
- **右栏默认不渲染**（2026-10-06 三次增补）：默认两栏工作面（侧栏 + 中栏铺满）；改动 tab 下点击工作区文件、或历史 tab 下点击提交时才出现——分别展示工作文件 diff / 提交详情（点详情内文件再在下半展开 diff tab 区）。取消触发（再点同文件收起、切换 tab）即整体收起；右上角 ⨯ 关闭按钮等效移除触发条件（改动 tab 收起 diff，历史 tab 取消选中提交）。
- 右栏**上下文感知**（2026-10-06 二次增补）：历史 tab 下，提交详情常驻，**文件 diff 区默认不展示**——点击上方文件列表才在下半展开多 tab diff 区（可关闭）；改动 tab 下无详情面板，点击工作区文件行后整栏展示该文件 diff（`get_worktree_diff` 拉取，头部带已暂存/未暂存徽标），再次点击同一文件收起；工作区选中文件在 refresh 时仍存在则静默刷新 diff，已消失则自动收起。
- 栏宽**可拖拽调整**（2026-10-06 增补）：**侧栏为像素级宽度**（140–340px，默认 216），独立拖拽手柄 + localStorage 持久化（`fumigit.sidebar-width`）——右栏显隐、中栏 tab 切换都不会让侧栏宽度跳动（不再参与面板组的百分比归一化）。中/右栏由 react-resizable-panels（v3 PanelGroup）管理：右栏 24–52% / 图谱 ≥30%（占扣除侧栏后的宽度），右栏出现时默认 37%；上下 详情 ≥20% / diff ≥20%，右栏出现时默认 55:45；autoSaveId 持久化。分隔线 1px 视觉线 + 8px 命中区（`cursor-col/row-resize`），悬停命中区变 hover 色、细线变 accent，拖拽中保持高亮。
- 图谱列：SVG/Canvas 绘制，lane 步进 15px，节点 r=4（HEAD r=5.5，描边 2px 背景色）。lane 分配修正（2026-10-06）：同一提交被多个子提交预留的冗余槽位即时回收（否则 `--all` 多分支仓库 lane 一路膨胀、分支线被挤出画布）；图谱列宽随 laneCount 自适应（`graphWidth`，下限仍 96px），任何仓库分支线都不裁边。
- 行内信息（2026-10-06 改版，对标 IDEA Git log）：第一行 = 提交信息（truncate）；有引用时第二行 = ref 徽章（分支/远程/HEAD/标签，最多 4 个 + 溢出提示）；右侧紧凑列 = 作者头像+名字（92px）/ 相对时间（70px，悬停出绝对时间）/ 短 hash（56px）。所有被截断的列悬停出 tooltip；不再让徽章与标题挤在同一行换行。
- 侧栏点击分支/标签/远程（2026-10-06 增补）：**自动切到历史 tab**，选中其 tip 提交并将该行**滚动到列表顶部**（行高恒定直接换算 scrollTop；重复点击同一引用也重新跳转）。
- 侧栏**分支分组**（2026-10-06 增补，VS Code 源代码管理风格）：分支按首个 "/" 前缀折叠为文件夹（组名 + 数量角标，可展开），根分支平铺；组内外按名称排序，成员行缩进显示剩余名、悬停出「完整分支名 → 短hash」；折叠状态持久化 localStorage（`fumigit.expanded-branch-groups`）。
- 侧栏**远程分组**（2026-10-07 增补，与分支同风格）：远程先按远端名折叠为云图标分组（组名 + 数量角标，可展开），组内复用分支式 "/" 分层（无 "/" 的根分支平铺，含 "/" 的按首段折叠为文件夹，成员缩进加深一级）；远端名按名称排序，组内外按名称排序，悬停出「完整远程 ref → 短 hash」；两层折叠状态分别持久化 localStorage（`fumigit.expanded-remote-groups` / `fumigit.expanded-remote-subgroups`）。
- **工作区文件多选**（2026-10-07 增补，VS Code 源代码管理风格）：Ctrl/Cmd+点击切换选中、Shift+点击组内范围选择、普通点击清空选择并查看 diff；右键点中所选 → 批量菜单（暂存/取消暂存所选、丢弃所选带确认），点在未选中行则单选该行。选择不跨「已暂存/未暂存」分组，状态刷新时自动修剪已消失的文件。悬停动作按钮始终占位（invisible→visible），不得因出现/消失引起行高或文本截断跳动。
- 从落选变体吸收：B 的"搜索框 Ctrl K 提示"样式进入工具栏；B 的底部状态栏**暂不引入**（A 的右下工作区已承担该职责，避免重复）。
- **推送按钮为分裂按钮**（2026-10-07 增补，多远程仓库）：主体「推送」= 推到当前分支的上游远程（等价 `git push`，无上游仍走「建立上游关联」弹框）；右侧 chevron 半格（`rounded-l-none`，1px `--border-soft` 作右分隔线）展开远程菜单，复用右键菜单基元：上游远程置顶并带 `hint`「当前上游」，其余远程逐项列出，多于一个远程时附「推送到全部远程」。单远程仓库 caret 禁用。菜单项只执行 `push <remote> <branch>:<branch>`，**不改上游关联**；「全部远程」逐个推送并汇总哪些没推上。

## 3. 状态徽章

- 分支 ref：`--accent-soft` 底 + `--accent-ink` 字；远程 ref（`<远程名>/*`，如 `origin/*`、`gitee/*`，前缀取自真实远程列表而非写死 origin）：描边幽灵款；HEAD：`--accent` 实底白字；标签 `⚑`：琥珀软底。
- 文件状态：M 琥珀 / A 绿 / D 玫红，14px 圆角小方块。
- 分支树计数：↑2 绿 / ↓1 琥珀。

## 4. 交互基元（2026-10-07 增补：日常写路径批次）

- **右键菜单**：受控组件，调用方持 `{x, y, items}` 状态。面板底 `--panel`、1px `--border` 描边、圆角 8px、`--card-shadow`，最小宽 150px；条目高 28px、字号 12px、左右内边距 10px，悬停底 `--hover`；危险项字色 `--bad`、悬停底 `rgba(242,112,138,.10)`；禁用项 45% 透明不出悬停。点击外部 / Escape / 滚动 / 窗口失焦即关闭；出现位置避让视口边缘（留 6px）。
- **菜单条目组织**（2026-10-07 增补）：条目按语义分组，组间插 `{kind:"separator"}` 分隔线（1px `--border-soft`，左右内缩 10px、上下各 4px）；组序为「移动引用 → 基于此提交派生改动 → 破坏性改写指针」，破坏性项必须 `danger` 且沉到末组；侧栏分支菜单同构（移动引用 / 增删改名 / 破坏性）。标签只留中文动宾短语（`新建分支…` 而非「在此新建分支…」），`…` 一律表示后续有对话框；git 术语（cherry-pick / revert）走右侧 `hint` 灰字，不塞进标签；指向具体对象的动作带短 id（如 `重置当前分支到 a1b2c3d…`）。术语统一用「摘取」（cherry-pick）、「还原」（revert），禁用「择取」。
- **确认/选择对话框**：模态遮罩 `rgba(0,0,0,.45)`；内容面板 `--panel`、圆角 10px、`--card-shadow`、宽 380px，高度上限 70vh 溢出滚动。标题 13px/600；正文 12px `--dim`；受影响文件列表为等宽 11.5px 的 `--panel2` 底滚动区（上限 40vh）。动作按钮右对齐：主 = btn-primary、危险 = btn-danger（bad 底白字）、次 = btn-ghost；取消按钮固定最右，Escape 等效取消。带输入框时自动聚焦并全选，Enter 触发首个主/危险动作。按钮文字不换行（whitespace-nowrap），动作行放不下时整体折行（flex-wrap）——长说明放正文，不塞进按钮标签。
- **安全拦截对话框**（脏工作树模型）：迁出 / reset --hard / 丢弃等销毁类操作前必须经此对话框；正文说明后果、列出受影响文件、提供多个去向选项（如「带着改动迁出 / stash 后迁出 / 取消」）。Enter 只绑定主动作（primary），危险动作（danger）必须显式点击。
- **语义色软底令牌**（2026-10-07 增补）：`--warn-soft`（深 `rgba(224,166,75,.10)` / 浅 `.12`）、`--bad-soft`（深 `rgba(242,112,138,.12)` / 浅 `rgba(179,56,78,.08)`），用于合并横幅、对话框错误条等语义色大面积底色；组件派生令牌，定义在 index.css。
