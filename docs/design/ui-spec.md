# FumiGit UI 设计规范 v1

> 2026-10-06 由 UI 原型对比确定。原型问题："FumiGit 主界面应该长什么样？哪种布局最'专业好看'？"
> 三个结构化变体（工作台三栏 / 沉浸图谱 / 仓库地图）经浏览器实际渲染对比后，**变体 A（工作台三栏）胜出**。
> 全量原型（含落选变体与切换器）归档于分支 `prototype/ui-variants`（`prototype/index.html`）。

## 1. 布局：三栏工作台

```
┌────────────────────────────────────────────────────────────┐
│ titlebar 34px  FumiGit — 仓库名                    ─ ▢ ✕  │
├────────────────────────────────────────────────────────────┤
│ toolbar 42px  仓库▾ · 分支 · 拉取/推送/抓取         搜索…  │
├──────────┬──────────────────────────────┬──────────────────┤
│ 侧栏     │ [改动] [历史] tab             │ 提交详情          │
│ 216px    │ 历史：提交图谱（默认，主角）   │ （消息/元信息/    │
│ 分支↑↓   │      行高 52px，图宽 96px     │  文件列表）       │
│ 贮藏     │ 改动：暂存/未暂存 + 提交框     ├──────────────────┤
│ 标签     │                              │ 文件 diff（多tab）│
│ 远程     │                              │                  │
└──────────┴──────────────────────────────┴──────────────────┘
```

- 中栏**改动 / 历史 双 tab**（2026-10-06 增补，GitHub Desktop 式）：**默认选中「改动」**；历史 = 提交图谱列表（图谱是主角）；改动 = 工作区（已暂存/未暂存分组 + 提交信息框），自右下面板整体迁入。tab 选中态用 accent-soft 底 + accent 描边；两个 tab 保持挂载，来回切换不丢图谱滚动位置。
- **右栏默认不渲染**（2026-10-06 三次增补）：默认两栏工作面（侧栏 + 中栏铺满）；改动 tab 下点击工作区文件、或历史 tab 下点击提交时才出现——分别展示工作文件 diff / 提交详情（点详情内文件再在下半展开 diff tab 区）。取消触发（再点同文件收起、切换 tab）即整体收起；右上角 ⨯ 关闭按钮等效移除触发条件（改动 tab 收起 diff，历史 tab 取消选中提交）。
- 右栏**上下文感知**（2026-10-06 二次增补）：历史 tab 下，提交详情常驻，**文件 diff 区默认不展示**——点击上方文件列表才在下半展开多 tab diff 区（可关闭）；改动 tab 下无详情面板，点击工作区文件行后整栏展示该文件 diff（`get_worktree_diff` 拉取，头部带已暂存/未暂存徽标），再次点击同一文件收起；工作区选中文件在 refresh 时仍存在则静默刷新 diff，已消失则自动收起。
- 栏宽**可拖拽调整**（2026-10-06 增补）：**侧栏为像素级宽度**（140–340px，默认 216），独立拖拽手柄 + localStorage 持久化（`fumigit.sidebar-width`）——右栏显隐、中栏 tab 切换都不会让侧栏宽度跳动（不再参与面板组的百分比归一化）。中/右栏由 react-resizable-panels（v3 PanelGroup）管理：右栏 24–52% / 图谱 ≥30%（占扣除侧栏后的宽度），右栏出现时默认 37%；上下 详情 ≥20% / diff ≥20%，右栏出现时默认 55:45；autoSaveId 持久化。分隔线 1px 视觉线 + 8px 命中区（`cursor-col/row-resize`），悬停命中区变 hover 色、细线变 accent，拖拽中保持高亮。
- 图谱列：Canvas 绘制，lane 步进 18px（`GRAPH_PAD=14`），节点 r=5 空心圆环（描边 1.6，外缘 11.6px，列内留 6px 呼吸）。**不要照抄 VS Code 的 11px**——那是给它自己只有几条 lane 的仓库用的；`--all` 多分支仓库（本项目实测 20 分支 → 21 lane）挤在 11~12px 会连成一片。间距与总宽是直接对冲的：18px × 21 列 = 378px 是这个仓库并发展示的诚实代价，真正能降下来只有减少并发 lane（`get_log` 去掉 `--all`，改查当前分支 + 加开关）。**列宽按视口自适应**（`windowCols` + `graphWidth`，下限 96px）：只用当前视口（含上下各 4 行缓冲）内实际有墨的列数，不用全局 `laneCount`——后者是整份列表最宽的那处（实测 20 分支：全局 21 列 / 视口平均 13 列），否则窄处会留大片空白、提交信息被推远。缓冲行数不能完全消除跳变（约 9% 的滚动位置会变），但那是真实的分支扇出，不该被抹掉。
- 图谱连线几何（2026-10-09 重做，对齐 oil-git `src/graph.ts` 的 `curve()`）：**限幅贝塞尔**，控制点离端点 `bend = min(|Δy| * 0.45, BEND_MAX=38px)`。跨度大的边只有首尾各 38px 在弯，中间路程就是垂直直线。**关键教训：控制点不得取父子行的中点**——那样跨度越大鼓包越夸张，多分支仓库必然打结（这才是「一团乱麻」的真正成因，不是曲线形状本身的问题）。此前试过的「VS Code 式行内正交圆角走线 + `rows[]` 行快照」已整体废弃：它为绕开 lane 压缩问题引入了大量复杂度，而压缩问题本身已由下面的空槽复用消除。
- lane 分配（2026-10-09 重做，对齐 oil-git `layoutGraph`）：**优先复用空槽位、只记 max 水位、不压缩下标**——同一条线列号终身稳定，不会在行间横移。节点出列即释放该槽，first parent 原地接棒，其余 parent 各占一列。**旧实现空列 `splice` 压缩已废弃**：下标不断左移会让同一条线在不同行占据不同列，产生一堆横移折线。颜色按列号取（`BRANCH_PALETTE[lane % 6]`，6 色，相邻位拉开色相），列稳定即颜色稳定。代价：父提交若不在可见集内会永久占一列（与 oil-git 同），但被 first-fit 复用机制约束在实际并发分支数以内。
- 父提交被过滤（搜索/过滤导致不可见）→ 画**虚线 stub** 到列表底部（`strokeDasharray 4 4`，edge 标 `pending`），表示历史在可见范围之外继续，而非直接丢边。
- 提交节点（2026-10-09 重做，对齐 oil-git）：**一律空心圆环**，底色填充盖住穿过的连线（不用半透明，避免连线透出显脏），描边取列色；**选中时填充 accent**。HEAD 额外套一圈 r=11、alpha .13 的同色柔光晕。不再按 merge 区分形状。
- 行内信息（2026-10-06 改版，对标 IDEA Git log）：第一行 = 提交信息（truncate）；有引用时第二行 = ref 徽章（分支/远程/HEAD/标签，最多 4 个 + 溢出提示）；右侧紧凑列 = 作者头像+名字（92px）/ 相对时间（70px，悬停出绝对时间）/ 短 hash（56px）。所有被截断的列悬停出 tooltip；不再让徽章与标题挤在同一行换行。
- 侧栏点击分支/标签/远程（2026-10-06 增补）：**自动切到历史 tab**，选中其 tip 提交并将该行**滚动到列表顶部**（行高恒定直接换算 scrollTop；重复点击同一引用也重新跳转）。
- 侧栏**分支分组**（2026-10-06 增补，VS Code 源代码管理风格）：分支按首个 "/" 前缀折叠为文件夹（组名 + 数量角标，可展开），根分支平铺；组内外按名称排序，成员行缩进显示剩余名、悬停出「完整分支名 → 短hash」；折叠状态持久化 localStorage（`fumigit.expanded-branch-groups`）。
- 侧栏**远程分组**（2026-10-07 增补，与分支同风格）：远程先按远端名折叠为云图标分组（组名 + 数量角标，可展开），组内复用分支式 "/" 分层（无 "/" 的根分支平铺，含 "/" 的按首段折叠为文件夹，成员缩进加深一级）；远端名按名称排序，组内外按名称排序，悬停出「完整远程 ref → 短 hash」；两层折叠状态分别持久化 localStorage（`fumigit.expanded-remote-groups` / `fumigit.expanded-remote-subgroups`）。
- 侧栏引用**数据源独立于分页历史**（2026-10-09 修正）：分支/标签/远程一律取自 `list_refs`（`git for-each-ref` 全量列表，store.refs），**不再从图谱提交的 ref 装饰推导**——`get_log` 只在已加载的那几行上装饰 ref，tip 落在分页窗口之外的老分支/老标签会整个消失，且随滚动"突然冒出来"。同理标签不再 `slice(0, 20)` 静默截断，改为按创建时间倒序全量展示（行内样式不变）。点击引用时若 tip 尚未加载（refs 是全量的、图谱只加载了前若干页），先翻页找到它再定位；标签显示裸名（旧的 `tag:` 前缀由后端归一化掉）。
- 侧栏**顶层分区可折叠**（2026-10-24 增补）：「分支 / 贮藏 / 标签 / 远程」四个分区标题行 = 折叠 chevron + 中文名，点击标题行切换折叠（+ 动作按钮仅分支/贮藏有，折叠时仍可用）；折叠状态持久化 localStorage（`fumigit.sidebar-collapsed-sections`，记录折叠中的分区集合，缺席 = 展开）。stash 的界面文案统一译作「贮藏」（含空态「暂无贮藏」、对话框「贮藏改动」、安全拦截动作「贮藏后迁出 / 贮藏后硬重置」、Toast「已存入贮藏」）；git 字面量（`stash@{n}`）与菜单 hint（stash pop / apply）保留原文。
- 图谱选中行（2026-10-07 增补，2026-10-09 随节点改造更新）：选中行整块底色走加深令牌 `--sel-strong`（深 `rgba(124,127,242,.17)` / 浅 `rgba(84,87,228,.13)`），去掉左侧 2px 竖线。**图谱选中节点改为直接把 r=5 空心圆环填成 accent**（不再用「背景色间隙圈 + accent 细圈」两层描边）——所有节点一律底色填充 + 列色描边，选中即填充 accent，同样避免连线透出且少一层绘制。`--sel-bg` 保持原值供侧栏等其它选中态使用。
- **工作区文件多选**（2026-10-07 增补，VS Code 源代码管理风格）：Ctrl/Cmd+点击切换选中、Shift+点击组内范围选择、普通点击清空选择并查看 diff；右键点中所选 → 批量菜单（暂存/取消暂存所选、丢弃所选带确认），点在未选中行则单选该行。选择不跨「已暂存/未暂存」分组，状态刷新时自动修剪已消失的文件。悬停动作按钮始终占位（invisible→visible），不得因出现/消失引起行高或文本截断跳动。
- **工作区分组折叠**（2026-10-24 增补）：改动 tab 的「已暂存 / 未暂存」分组头可整块折叠——chevron 随状态旋转，点击组头标签区切换；折叠时组头保留计数与悬停批量动作。「冲突」组不折叠（操作进行中的紧迫态），其组头用隐身 chevron 占位保持色点左缘对齐。折叠状态持久化 localStorage（`fumigit.collapsed-work-groups`）。
- **修正上一次提交（amend）**（2026-10-24 增补）：提交框下方勾选「修正上一次提交」→ 信息框为空时预填 HEAD 完整原文（`%B`，取自 `get_last_commit_message`；已输入内容不覆盖），按钮文案变「修正上次提交」，允许零暂存的纯信息修正（`git commit --amend`；普通提交仍要求有已暂存改动）。提交成功后勾选自动复位。勾选时提示「已推送的提交修正后需强推」——不弹确认（与 VS Code 同级：勾选即意图），推送侧的强推拦截由既有流程承担。标签不带 git 术语后缀（用户偏好：面向用户的文案用中文动宾短语）。
- 从落选变体吸收：B 的"搜索框 Ctrl K 提示"样式进入工具栏；B 的底部状态栏**暂不引入**（A 的右下工作区已承担该职责，避免重复）。
- **推送按钮为分裂按钮**（2026-10-07 增补，多远程仓库）：主体「推送」= 推到当前分支的上游远程（等价 `git push`，无上游仍走「建立上游关联」弹框）；右侧 chevron 半格（`rounded-l-none`，1px `--border-soft` 作右分隔线）展开远程菜单，复用右键菜单基元：上游远程置顶并带 `hint`「当前上游」，其余远程逐项列出，多于一个远程时附「推送到全部远程」。单远程仓库 caret 禁用。菜单项只执行 `push <remote> <branch>:<branch>`，**不改上游关联**；「全部远程」逐个推送并汇总哪些没推上。
- **仓库切换器**（2026-10-24 增补）：工具栏左上角仓库名改为下拉按钮（绿点 + 名称 + chevron，悬停 hover 底，tooltip 出完整路径），菜单挂按钮下方（复用右键菜单基元）：最近仓库按序列出（当前仓库不列，`hint` 显示路径）→「打开仓库目录…」（系统目录选择器，选定即打开并进最近列表——**应用内添加仓库的入口**）→「关闭仓库」（清状态回欢迎页；移除最近条目的 ⨯ 仍只在欢迎页）。**侧栏「仓库」分区随之移除**，侧栏自「分支」起（分支 / 贮藏 / 标签 / 远程）。欢迎页最近列表行单行排布：仓库名不缩、路径 truncate 省略、悬停行出完整路径 tooltip，容器 520px（2026-10-24 二次增补）。
- **分支切换下拉**（2026-10-24 增补，IDEA Git branches 式）：工具栏分支 chip 点击展开下拉面板（复用右键菜单基元，宽 260px）：「本地分支 / 远程分支」两组 header 分区 + 底部「新建分支…」；当前分支禁用置 ✓ 并提示「当前分支 ↑n ↓n」。左键行 = 切换——本地分支走带脏工作树拦截的迁出；远程分支有同名本地分支（origin/feat/x ↔ feat/x）直接切，否则弹「新建分支」对话框预填短名、以其 tip 为起点（git switch DWIM 的显式化）。右键行 = 该分支操作菜单（本地：迁出 / 合并 / 新建 / 重命名 / 删除；远程：迁出 / 合并），与侧栏分支右键菜单共用 `components/branchMenu.ts` 构建函数。ContextMenu 基元相应扩展：header 分组行、active 行 ✓ 槽位、行 title tooltip、面板内滚动不误关闭（max-h 70vh）、可选 width。变基（rebase）尚无后端命令，菜单暂不含。

### 字体

- UI：`"IBM Plex Sans", "PingFang SC", "Microsoft YaHei", sans-serif`
- 等宽（hash/diff）：`"IBM Plex Mono", "Cascadia Code", Consolas, monospace`
- 基准字号 13px，行内元信息 11.5–12px，diff 11.5px。
- **字号 rem 化与字号设置**（2026-10-24 增补）：上表 px 值为设计基准，代码里**一律写 rem**（13px = `0.8125rem`，除数 16 = root 基准）。用户「字号」设置 = root `font-size = 16px × 比例`（85%–130%，步进 5%，默认 100%），只缩放文字、不缩放布局。**两个配套硬规约**：① `--spacing` 冻结为 `4px`（Tailwind 默认 0.25rem 会随 root 缩放，间距/尺寸必须与字号解耦；新增间距走 spacing 刻度或 px）；② 与字号配对的行高用无单位比例（如 `leading-[1.38]`），固定 px 行高放大后会裁切文字。**禁止新增 px 字号**。
- **用户字体覆盖**（2026-10-24 增补）：界面 / 等宽字体可在设置对话框选预设覆盖（UI：system-ui / Segoe UI / 微软雅黑 / 苹方 / 思源黑体；等宽：Cascadia Code / Consolas / JetBrains Mono）。生效机制 = `html[data-ui-font=<键>]` / `[data-mono-font=<键>]` 钩子 + index.css 逐预设手写规则——`@theme inline` 的字体栈是编译期展开的，改 CSS 变量对已编译类无效。预设键与 CSS 规则一一对应，新增预设两处同步。
- **界面缩放**（2026-10-24 增补）：`Ctrl+=` 放大 / `Ctrl+-` 缩小 / `Ctrl+0` 还原，步进 10%，范围 60%–180%，与「字号」相互独立（缩放动整页含图标间距，字号只动文字）。实现优先 webview `setZoom`（原生页面缩放，Canvas 图谱按新比例重栅格化），调用失败退 CSS `zoom`；capabilities 需 `core:webview:allow-set-webview-zoom`。缩放与字号均存 AppConfig（`set_appearance` 命令整体保存），启动 hydrate 恢复。
- **字体本地内置**（2026-10-24 增补）：IBM Plex Sans（400/500/600）与 IBM Plex Mono（400/500）经 `@fontsource` 随应用打包（index.css 顶部 `@import`），index.html 不再引 Google Fonts——桌面应用不依赖网络与用户已装字体，离线/首屏不退回微软雅黑。中文继续走系统栈（PingFang/雅黑），字体栈本身不变；用户字体覆盖机制（`data-ui-font` 钩子）不受影响。

## 3. 状态徽章

## 4. 交互基元（2026-10-07 增补：日常写路径批次）

- **右键菜单**：受控组件，调用方持 `{x, y, items}` 状态。面板底 `--panel`、1px `--border` 描边、圆角 8px、`--card-shadow`，最小宽 150px；条目高 28px、字号 12px、左右内边距 10px，悬停底 `--hover`；危险项字色 `--bad`、悬停底 `rgba(242,112,138,.10)`；禁用项 45% 透明不出悬停。点击外部 / Escape / 滚动 / 窗口失焦即关闭；出现位置避让视口边缘（留 6px）。（2026-10-24 增补：支持 header 分组行、active 行 ✓ 标记、行 title tooltip、面板内滚动 max-h 70vh 不误关闭、可选 width，供分支下拉等长列表复用。）
- **菜单条目组织**（2026-10-07 增补）：条目按语义分组，组间插 `{kind:"separator"}` 分隔线（1px `--border-soft`，左右内缩 10px、上下各 4px）；组序为「移动引用 → 基于此提交派生改动 → 破坏性改写指针」，破坏性项必须 `danger` 且沉到末组；侧栏分支菜单同构（移动引用 / 增删改名 / 破坏性）。标签只留中文动宾短语（`新建分支…` 而非「在此新建分支…」），`…` 一律表示后续有对话框；git 术语（cherry-pick / revert）走右侧 `hint` 灰字，不塞进标签；指向具体对象的动作带短 id（如 `重置当前分支到 a1b2c3d…`）。术语统一用「摘取」（cherry-pick）、「还原」（revert），禁用「择取」。
- **确认/选择对话框**：模态遮罩 `rgba(0,0,0,.45)`；内容面板 `--panel`、圆角 10px、`--card-shadow`、宽 380px，高度上限 70vh 溢出滚动。标题 13px/600；正文 12px `--dim`；受影响文件列表为等宽 11.5px 的 `--panel2` 底滚动区（上限 40vh）。动作按钮右对齐：主 = btn-primary、危险 = btn-danger（bad 底白字）、次 = btn-ghost；取消按钮固定最右，Escape 等效取消。带输入框时自动聚焦并全选，Enter 触发首个主/危险动作。按钮文字不换行（whitespace-nowrap），动作行放不下时整体折行（flex-wrap）——长说明放正文，不塞进按钮标签。
- **安全拦截对话框**（脏工作树模型）：迁出 / reset --hard / 丢弃等销毁类操作前必须经此对话框；正文说明后果、列出受影响文件、提供多个去向选项（如「带着改动迁出 / 贮藏后迁出 / 取消」）。Enter 只绑定主动作（primary），危险动作（danger）必须显式点击。
- **语义色软底令牌**（2026-10-07 增补）：`--warn-soft`（深 `rgba(224,166,75,.10)` / 浅 `.12`）、`--bad-soft`（深 `rgba(242,112,138,.12)` / 浅 `rgba(179,56,78,.08)`），用于合并横幅、对话框错误条等语义色大面积底色；组件派生令牌，定义在 index.css。
- **文本选中策略**（2026-10-24 增补）：全局 `user-select: none`（应用外壳与点选密集面：工具栏、侧栏、历史列表、图谱、diff 行号列），阅读性内容面逐处 opt-in `select-text`——提交详情（主题/正文/作者行/hash/文件路径）、diff 内容列、冲突视图三方内容与冲突块。`::selection` 底色统一 `--accent-soft`。
- **设置对话框**（2026-10-24 增补）：工具栏主题按钮旁齿轮入口。模态视觉复用确认对话框基元（遮罩 `rgba(0,0,0,.45)`、`--panel` 底、圆角 10px、宽 420px、上限 70vh），但**表单内容不走 DialogHost**（那是确认动作流），独立 `SettingsDialog` 组件。分区：外观（主题三选分段，与工具栏循环按钮同一状态源）/ 字体（界面 + 等宽两个预设下拉，附等宽 hash 预览行）/ 大小（字号、缩放两个 stepper，− % + 与「还原 100%」，缩放行附快捷键提示）。**改动即时生效即时持久化，无保存按钮**；Escape 或点遮罩关闭。
- **浮层动效与高度层次**（2026-10-24 增补，系统样式打磨批次）：全部只动 `transform`/`opacity`（不触发回流），`prefers-reduced-motion` 由 index.css 全局规则统一关闭。① 右键菜单/下拉面板进场 = `menu-in`（130ms，上浮 4px + scale .98，ease-out）；**transform-origin 自适应翻转**——被视口下缘顶上去的菜单锚点换 `bottom left`。② 确认/设置对话框进场 = 遮罩 `overlay-in`（160ms 淡入）+ 面板 `dialog-in`（200ms，上浮 8px + scale .97，自定义贝塞尔）。③ 深色 `--card-shadow` 由单层 1px 改双层（近 1px + 远 10px/32px）——浮在内容上的面板（菜单/对话框/Toast）需要远投影表达高度，浅色本就是双层不变。④ 欢迎页逐项浮升进场（`rise-in` 420ms，logo → 按钮 → 最近列表以 70ms 步进 stagger）。⑤ 欢迎页背景加**图谱母题** SVG：与 Canvas 图谱同一套限幅贝塞尔 / 空心节点 / 6 色调色板（主干 HEAD 填充 + 柔光晕同画法），整体 50% 透明 + radial mask 融边，只留氛围。⑥ 工具栏仓库/分支下拉的 chevron 随开合旋转 180°（150ms）。⑦ 右栏占位空态（详情/diff「点击查看」、加载中）统一为 图标 22px/1.5 描边 + 文案 居中竖排，与图谱空态同构。⑧ **可点元素统一手型光标**：全局规则 `button/[role=button]/[role=menuitem]/select`（非禁用）`cursor: pointer`——原生 button 默认箭头是浏览器规范行为，只有 .btn-* 类显式给过 pointer，散落的裸按钮（侧栏行/菜单条目/tab/下拉触发器/关闭按钮）会退回箭头；禁用态保持箭头。禁止再给单个按钮手写 `cursor-pointer`（div 点击目标除外，仍显式声明）。
